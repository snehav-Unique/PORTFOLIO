# Sneha Portfolio

A responsive personal portfolio built with Next.js and React.

## Features

- Animated Rubik's cube introduction
- Portrait-led landing section
- Interactive stacked project cards
- Animated project detail dialogs
- LinkedIn, GitHub, and email contact links
- Responsive desktop and mobile layouts
- Reduced-motion accessibility support

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Project structure

- `app/page.tsx` contains the portfolio content and interactions.
- `app/Stack.tsx` contains the interactive project stack.
- `app/globals.css` contains the complete responsive design and animations.
- `public/` contains the portrait, project preview, and social icons.
